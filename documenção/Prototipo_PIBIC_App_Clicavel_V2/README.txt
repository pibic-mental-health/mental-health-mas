Protótipo PIBIC V2

Novidades desta versão:
- identidade visual mais roxa;
- cadastro e login simulados;
- nome do usuário usado na Home, Chat e Apoio;
- DASS-21 completa;
- chat multiagente simulado;
- fluxo de alteração fisiológica -> contexto -> apoio -> feedback;
- tela de segurança;
- botão clicável "Ligar para o CVV — 188" usando tel:188;
- smartwatch mantido como fonte passiva de contexto.

Abra index.html no navegador.
Este é um protótipo de interface: não há BLE, JADE, PostgreSQL ou autenticação real nesta versão.
